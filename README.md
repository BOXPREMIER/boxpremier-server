# Boxpremier Server

## Descripción
Aplicación backend para Boxpremier, proyecto de suscripción de vinos.  

#### Servidor / Framework
- Node.js
- Express

#### Base de datos
- MongoDB
- Mongoose

#### Seguridad / Autenticación
- Bcrypt
- JSON Web Token (JWT)
- Helmet

#### Middleware / Comunicación
- CORS
- Express-Validator
- Morgan

#### Configuración / Entorno
- Dotenv

#### Monitoreo y scripts
- Nodemon
- Cross-Env

#### Testing
- Jest
- Supertest
